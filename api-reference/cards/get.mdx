---
title: Get card
api: POST /card/get-card
description: Fetch one cardholder's live card, including balance, spend, card number, and security code.
---

Loads the cardholder's current card from the issuer and returns it with `card_number`, `security_code`, and `total_card_spend`.

Closed cards (`terminated` or `terminating`) are not returned. Use [transactions](/api-reference/cards/transactions) for history on a closed card.

<ParamField body="user_id" type="string" required>
  Cardholder id returned by [create card user](/api-reference/cards/create-user).
</ParamField>

<ResponseField name="data.total_card_spend" type="number">
  Total spend reported for the card.
</ResponseField>

### Errors

| Message | When |
|---------|------|
| `Card user not found.` | `user_id` is missing for this partner |
| `Card not found.` | The cardholder has no open card |
| `Partner not found.` | The API key does not match a partner |
| `An unexpected error occurred. Please try again.` | The issuer could not return the card |

<RequestExample>
```bash
curl -X POST "{{base_url}}/card/get-card" \
  -H "x-api-key: YOUR_CONSUMER_KEY" \
  -H "Content-Type: application/json" \
  -d '{"user_id": "7c9e6679-7425-40de-944b-e07fc1f90ae7"}'
```
</RequestExample>
