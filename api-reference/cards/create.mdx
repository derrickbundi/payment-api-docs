---
title: Create card
api: POST /card/create
description: Issue one USD virtual card for online checkout and load the opening amount.
---

Issues one virtual card in **USD** for online checkout and loads `amount` onto it. Each cardholder can have one card.

`is_non_subscription` controls auto-renewal. Leave it `true` (the default) to block recurring charges. Set it to `false` when a merchant should be able to store the card and bill it again, such as a streaming or SaaS plan. Contactless is off for cards created here.

The response includes `card_number` and `security_code`. See the [card object](/guides/cards#card-object).

<ParamField body="user_id" type="string" required>
  Cardholder id returned by [create card user](/api-reference/cards/create-user).
</ParamField>

<ParamField body="amount" type="number" required>
  Opening balance in USD. Must be greater than `0.9`.
</ParamField>

<ParamField body="brand" type="string" required>
  `visa` or `mastercard`.
</ParamField>

<ParamField body="title" type="string">
  Display title. Defaults to the cardholder's full name.
</ParamField>

<ParamField body="color" type="string">
  `blue`, `black`, `purple`, `orange`, or `yellow`. Defaults to `black`.
</ParamField>

<ParamField body="is_non_subscription" type="boolean">
  `true` (default) blocks merchant auto-renewal. `false` allows a merchant to charge the card again when a subscription renews.
</ParamField>

### Errors

| Message | When |
|---------|------|
| First validator error | `user_id` is missing, `amount` is not greater than `0.9`, or `brand` / `color` is invalid |
| `Card user not found.` | `user_id` is unknown, or the cardholder was not provisioned |
| `Card user already has a card.` | This cardholder already has a card |
| `An unexpected error occurred. Please try again.` | The card could not be issued |

<RequestExample>
```bash
curl -X POST "{{base_url}}/card/create" \
  -H "x-api-key: YOUR_CONSUMER_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "user_id": "7c9e6679-7425-40de-944b-e07fc1f90ae7",
    "amount": 25,
    "brand": "visa",
    "title": "Ada Lovelace",
    "color": "black",
    "is_non_subscription": true
  }'
```
</RequestExample>
