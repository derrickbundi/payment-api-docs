---
title: Fund card
api: POST /card/fund
description: Add funds to a cardholder's open USD card.
---

Credits `amount` to the cardholder's open card. The card currency is USD for cards issued by [create card](/api-reference/cards/create).

The response is a [card object](/guides/cards#card-object) without `card_number` or `security_code`. `balance` is the balance after the credit.

<ParamField body="user_id" type="string" required>
  Cardholder id returned by [create card user](/api-reference/cards/create-user).
</ParamField>

<ParamField body="amount" type="number" required>
  Amount to add, in the card currency.
</ParamField>

### Errors

| Message | When |
|---------|------|
| First validator error | `user_id` is missing or `amount` is not a number |
| `Card user not found.` | `user_id` is missing for this partner |
| `Card not found.` | The cardholder has no open card |
| `Partner not found.` | The API key does not match a partner |
| `An unexpected error occurred. Please try again.` | The card could not be funded |

<RequestExample>
```bash
curl -X POST "{{base_url}}/card/fund" \
  -H "x-api-key: YOUR_CONSUMER_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "user_id": "7c9e6679-7425-40de-944b-e07fc1f90ae7",
    "amount": 10
  }'
```
</RequestExample>
