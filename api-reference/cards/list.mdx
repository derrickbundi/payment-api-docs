---
title: List cards
api: POST /card/all
description: List virtual cards for your partner account, including card number and security code.
---

Returns cards for the authenticated partner, newest first. Each card includes `card_number` and `security_code`. See the [card object](/guides/cards#card-object).

<ParamField body="page" type="integer">
  Page number, starting at `1`. Defaults to `1`.
</ParamField>

<ParamField body="limit" type="integer">
  Page size. Must be at least `1`. Defaults to `20`.
</ParamField>

<ResponseField name="data.cards" type="array">
  [Card objects](/guides/cards#card-object), including `card_number` and `security_code`.
</ResponseField>

<ResponseField name="data.page" type="integer">
  Page that was returned.
</ResponseField>

<ResponseField name="data.limit" type="integer">
  Page size that was applied.
</ResponseField>

<ResponseField name="data.total" type="integer">
  Total cards for this partner.
</ResponseField>

<RequestExample>
```bash
curl -X POST "{{base_url}}/card/all" \
  -H "x-api-key: YOUR_CONSUMER_KEY" \
  -H "Content-Type: application/json" \
  -d '{"page": 1, "limit": 20}'
```
</RequestExample>
