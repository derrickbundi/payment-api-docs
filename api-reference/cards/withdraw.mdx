---
title: Withdraw from card
api: POST /card/withdraw
description: Debit a cardholder's open card. Amount must be greater than 0.9.
---

Debits `amount` from the cardholder's open card. `amount` must be greater than `0.9`.

The response is a [card object](/guides/cards#card-object) without `card_number` or `security_code`. `balance` is the balance after the debit.

<ParamField body="user_id" type="string" required>
  Cardholder id returned by [create card user](/api-reference/cards/create-user).
</ParamField>

<ParamField body="amount" type="number" required>
  Amount to remove, in the card currency. Must be greater than `0.9`.
</ParamField>

### Errors

| Message | When |
|---------|------|
| First validator error | `user_id` is missing or `amount` is not greater than `0.9` |
| `Card user not found.` | `user_id` is missing for this partner |
| `Card not found.` | The cardholder has no open card |
| `Card has insufficient balance.` | The card cannot cover `amount` |
| `Partner not found.` | The API key does not match a partner |
| `An unexpected error occurred. Please try again.` | The withdrawal could not be completed |

<RequestExample>
```bash
curl -X POST "{{base_url}}/card/withdraw" \
  -H "x-api-key: YOUR_CONSUMER_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "user_id": "7c9e6679-7425-40de-944b-e07fc1f90ae7",
    "amount": 10
  }'
```
</RequestExample>
