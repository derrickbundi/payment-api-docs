---
title: List card users
api: POST /card/users
description: List cardholders for your partner account, with their cards.
---

Returns cardholders for the authenticated partner, newest first. Nested cards omit `card_number` and `security_code`. ID type and ID number are not included.

<ParamField body="page" type="integer">
  Page number, starting at `1`. Defaults to `1`.
</ParamField>

<ParamField body="limit" type="integer">
  Page size. Must be at least `1`. Defaults to `20`.
</ParamField>

<ResponseField name="data.users" type="array">
  Cardholders. Each item has `user_id`, `email`, `name`, `phone`, `country`, `state`, `city`, `address`, `zip_code`, and `cards`.
</ResponseField>

<ResponseField name="data.page" type="integer">
  Page that was returned.
</ResponseField>

<ResponseField name="data.limit" type="integer">
  Page size that was applied.
</ResponseField>

<ResponseField name="data.total" type="integer">
  Total cardholders for this partner.
</ResponseField>

<RequestExample>
```bash
curl -X POST "{{base_url}}/card/users" \
  -H "x-api-key: YOUR_CONSUMER_KEY" \
  -H "Content-Type: application/json" \
  -d '{"page": 1, "limit": 20}'
```
</RequestExample>
